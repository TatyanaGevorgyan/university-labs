# Lab 4 - Method Parameter Modifiers (in, out, ref, params)

## Խնդրի դրվածք և պահանջներ

* Մեթոդների մոդիֆիկատորներ: 
  * Ստեղծված են A(), B(), և C() static մեթոդները՝ համապատասխանաբար in, out և ref պարամետրերի մոդիֆիկատորների աշխատանքը ցուցադրելու համար։
* **Փոփոխական քանակով պարամետրեր (params):** 
  * Ստեղծված է SumValues(params int[] numbers) մեթոդը, որը գումարում է մուտքում տրվող ամբողջ թվերը (քանակը ֆիքսված չէ) և վերադարձնում արդյունքը։
* Main() մեթոդ: 
  * Ցուցադրված է այս բոլոր մեթոդների և մոդիֆիկատորների աշխատանքը գործողության մեջ։

## Ֆայլերի կառուցվածքը
* **Program.cs** — Պարունակում է Main մեթոդը, ինչպես նաև A, B, C և SumValues մեթոդների իրականացումն ու թեստավորումը։
