# Lab 3 - String, Formatting, Enum & Console Input

##  Խնդրի պահանջներ

* Movie.cs կլասի ստեղծում: 
  * Պարունակում է հետևյալ դաշտերը՝ Number (ֆիլմի համար), Title (ֆիլմի անուն), Year (տարեթիվ), MovieGenre (ֆիլմի ժանր՝ enum), Views (դիտումների քանակ), Likes (լայքերի քանակ)։
* Enum ժանրերի համար: 
  * Ստեղծված է 5 տարբերակ պարունակող Genre enum (օրինակ՝ Action, Comedy, Drama, SciFi, Horror)։
* Console-ից մուտքագրում և split: 
  * Տվյալները ընդունվում են ReadLine()-ի միջոցով, ժանրը գրվում է որպես 1-ից 5 թիվ, որից հետո ինֆորմացիան տեղավորվում է կլասի դաշտերում։
* Ռեյտինգի հաշվարկ: 
  * Ստեղծված է մեթոդ, որը հաշվում է ֆիլմի ռեյտինգը հետևյալ բանաձևով՝ SQRT(Likes ^ 2 / Views) և վերադարձնում double տիպի արժեք։
* ToString() մեթոդի override: 
  * Movie կլասի համար վերասահմանվել է ToString() մեթոդը հետևյալ ձևաչափով.
    * Ֆիլմի համարը՝ {4 տառաչափ, կցել աջ}
    * Ֆիլմի անունը՝ {15 տառաչափ, կցել ձախ}
    * Տարեթիվը՝ {8 տառաչափ, կցել ձախ և փակագծերի մեջ, օր․ (2011)}
    * Ֆիլմի ժանրը՝ {12 տառաչափ, տեքստային, կցել ձախ}
    * Ռեյտինգը՝ {8 տառաչափ, ստորակետից հետո 1000-րդական ճշտությամբ (:F3), պահպանելով նաև զրոները}
* Main() մեթոդի ֆունկցիոնալություն: 
  * Ծրագիրը սկզբում ընդունում է ֆիլմերի քանակը (օրինակ՝ 7), այնուհետև ցիկլով ընդունում է տվյալները, իսկ վերջում ցուցադրում ֆորմատավորված աղյուսակային տեսքով։
* Access Modifiers: 
  * Բոլոր մեմբերները և մեթոդները ստեղծված են public մուտքի մակարդակով։

##  Ֆայլերի կառուցվածքը
* **Program.cs** — Պարունակում է Main մեթոդը, կոնսոլից տվյալների ընդունման և տպման տրամաբանությունը։
* **Movie.cs** — Պարունակում է ֆիլմի դաշտերը, կոնստրուկտորը, ռեյտինգի հաշվարկման բանաձևը և ToString() մեթոդը։
* **Genre.cs** — Պարունակում է ժանրերի enum թվարկումը։
