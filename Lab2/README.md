# Lab 2 - Method Overloading & Default Parameters

## Խնդրի պահանջներ

* Մեթոդի ստեղծում: Ստեղծել static ToMultiplicate մեթոդը 3 տարբերակով (overloading)։
* Փոփոխականներ: Մեթոդները ընդունում են x և N փոփոխականները։
* Լռելյայն արժեք (Default parameter): $N$-ը ունի ըստ լռելյայն արժեք 2 և հանդիսանում է int տիպի։
* **Տվյալների տիպեր (x փոփոխականի համար):**
  * 1-ին տարբերակ՝ int x
  * 2-րդ տարբերակ՝ double x
  * 3-րդ տարբերակ՝ string x
* Վերադարձվող արժեք: Ֆունկցիան պետք է վերադարձնի $N$ հատ x-երի գումարը 
* Թեստավորում: Թեստավորել overloading-ի աշխատանքը Main() մեթոդում։
