# Lab 1 - SquareMatrix

## Խնդրի պահանջներ

* Ստեղծել կլաս, որը կպարունակի $N \times N$ չափերով մատրիցա։
* Կլասում պահել private դաշտեր $N$, $A$ և $B$ ամբողջ թվերի համար, և նրանց համար ապահովել { get; set; } մեթոդները կարճ գրելաձևով։
* Ստեղծել private FillMatrix անունով մեթոդ, որը կլրացնի մատրիցայի արժեքները $[A, B]$ միջակայքից պատահական թվերով։
* Ստեղծել public ShowMatrix մեթոդ, որը կարտածի մատրիցայի պարունակությունը։
* Ստեղծել մեթոդ, որը կվերադարձնի մատրիցայի կենտ թվերի քանակը։
* Պարամետրիզացված կոնստրուկտորով տեղադրել $N$, $A$ և $B$ դաշտերի արժեքները, որից հետո կանչել FillMatrix մեթոդը։
* Ցույց տալ կլասի ֆունկցիոնալությունը Main() մեթոդում։
  
##  Ֆայլերի կառուցվածքը
* **SquareMatrix.cs** - Պարունակում է մատրիցայի տրամաբանությունը, դաշտերը, կոնստրուկտորը և մեթոդները։
* **Program.cs** - Հիմնական մուտքի կետը (Main), որտեղ թեստավորվում է կլասի աշխատանքը։
